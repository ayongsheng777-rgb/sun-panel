## 二、后端改动（Go）

新建文件：
- `service/models/datatype/itemAddress.go` — `ItemAddress` 结构体（Id/Name/Url/Type/IsDefault/Sort/Enabled/OpenMethod/Color）。
- `service/lib/ai/ai.go` — 适配器模式：`Provider` 类型（deepseek/nvidia/custom）、`AIProviderConfig`、`AIConfig`、`AIModel`、`ModelTestResult`、`AIProviderAdapter` 接口、`OpenAICompatibleProvider`（Chat 走 JSON mode + 失败回退、`TestModel` 发 "Reply with OK"）、`ProviderManager`。
- `service/lib/ai/config.go` — `DefaultConfig()`（读环境变量 `AI_SEARCH_ENABLED`/`AI_DEFAULT_PROVIDER`/`DEEPSEEK_API_KEY`/`NVIDIA_API_KEY` 等）、`LoadConfig(userId)`、`SaveConfig(userId, cfg)`（存 `models.ModuleConfig` 的 `aiSearchConfig`）。
- `service/lib/ai/search.go` — `CandidateRecall`（标题0.40/描述0.20/lanUrl0.15/url0.10/地址名0.15/地址URL0.05，取 Top30）、`AISearch`（调用适配器，15s 超时，返回重排后的 itemId）、`parseRerankResult`（校验 itemId 去重，≤12）、`LocalFilter`（关键词兜底）、`FetchByIds`（按 id 回查 DB 取真实 URL）。
- `service/api/api_v1/panel/search.go` — `Search`（normal/ai，ai 失败自动降级并标 `fallback`）、`GetAIConfig`、`SaveAIConfig`、`ListModels`（GET `?provider=`）、`TestModels`（POST，测全部已启用 provider）。
- `service/router/panel/search.go` — 注册路由：`POST /panel/search`、`GET|POST /panel/ai/config`、`GET /panel/ai/models`、`POST /panel/ai/test`，均经 `middleware.LoginInterceptor`（用户隔离）。

修改文件：
- `service/models/itemIcon.go` — 新增 `AddressesJson string`（持久列）+ `Addresses []datatype.ItemAddress`（`gorm:"-"` 非持久）；`MigrateLegacyAddresses(db)`（幂等：仅处理 `addresses_json` 为空的历史行）、`buildLegacyAddresses`、`legacyType` 辅助函数。
- `service/api/api_v1/panel/itemIcon.go` — `Edit`/`AddMultiple`：保存前 `json.Marshal` 写入 `AddressesJson`；`Edit` 的 `updateField` 白名单加入 `"AddressesJson"`（**防止静默丢字段**）；`GetListByGroupId`：反序列化 `AddressesJson` → `Addresses`。
- `service/api/api_v1/panel/A_ENTER.go` — `ApiPanel` 挂载 `Search`。
- `service/router/panel/A_ENTER.go` — `InitSearch(routerGroup)`。
- `service/initialize/database/connect.go` — `CreateDatabase` 在 AutoMigrate 后调用 `models.MigrateLegacyAddresses(db)`（幂等迁移 `url`/`lanUrl` → `addresses`）。

**安全要点**：AI 只接收候选的 itemId/标题，**只回传 itemId**，最终 URL 一律由 DB 回查，杜绝 AI 编造外链。API Key 仅存后端（`ModuleConfig` + 环境变量），前端 `getAIConfig` 返回时含明文 Key（个人自托管可接受，见已知问题）。

## 四、数据结构

`item_icons` 表新增文本列 `addresses_json`，存储 `[]ItemAddress` 的 JSON：
```json
[
  { "id":"uuid", "name":"默认", "url":"https://a.com", "type":"https",
    "isDefault":true, "sort":0, "enabled":true, "openMethod":2, "color":"" }
]
```
兼容：`url`/`lanUrl` 旧字段保留作为兜底；启动迁移与编辑回填均基于 `addresses`。

## 七、已知问题 / 待确认

1. **后端未本地编译**：本环境无 Go 工具链，Go 代码未经 `go build` 验证。请在具备 Go 1.21+ 的机器执行 `go build ./...` 并自测 5 个接口。
2. **API Key 明文回传**：`getAIConfig` 会把 Key 明文返回前端（个人自托管可接受）。若需更严格，可改为返回 `hasKey` 掩码、保存时前端留空即保留。
3. **AI 模型联网**：`ListModels`/`TestModels`/`AISearch` 需后端能访问 DeepSeek/NVIDIA 或自定义 OpenAI 兼容端点（注意服务器出网/代理）。
4. **前端 `systemMonitor` 等组件**：为让全量 `type-check` 通过，顺带修了 3 处预存在的类型问题，逻辑行为不变。
